# Proyecto Integrador de Aprendizaje Automático

Este proyecto aplica el modelo GaussianNB para clasificar la presencia o ausencia de enfermedad cardíaca en pacientes, utilizando indicadores clínicos. El objetivo es construir un pipeline de clasificación, evaluar el desempeño del modelo y analizar el impacto de las variables desde una perspectiva probabilística. Los modelos bayesianos ofrecen una herramienta eficiente y explicativa, crucial para el diagnóstico temprano en sistemas de salud.
